# ADR-007：共享预处理变换契约（train/serve 一致）

- 状态：Accepted
- 日期：2026-08-04

## 背景
训练增强与推理前处理若各自实现，会导致"训练/服务预处理漂移"，模型静默掉点（§11 风险表）。

## 决策
- `backend/domain/preprocess/transform.py` 的 `to_model_input` 为**唯一**训练/推理共用变换（ADR-007）。
- 冻结占位参数：TARGET_SIZE=640、MEAN=(0,0,0)、STD=(1,1,1)、RGB_ORDER=False。
- 正式训练标定参数时，两条路径**同时更新**并在此记录变更；禁止单边修改。
- 契约测试 `test_transform.py::test_train_serve_parity` 保证逐元素一致。

## 后果
- 正面：消除静默掉点；测试可回归。
- 负面：调参需经 ADR 流程，不能随手改。

## 备选
- 训练与推理各自写预处理：开发快但风险高，否决。
