# ADR-004：本地优先 / 离线 / 加密（数据不出行）

- 状态：Accepted
- 日期：2026-08-04

## 背景
工业底片属敏感数据；现场可能无外网；合规要求可追溯、防篡改。

## 决策
- v1 全离线运行，数据库本地 SQLite（静态加密 AES-256）。
- 云能力仅以 `Syncer` 适配器存在（v1=LocalAdapter 空操作）；v3 优先联邦学习而非原始图像汇聚。
- 审计日志 append-only + 哈希链（§12.5）。

## 后果
- 正面：隐私合规、断网可用、云扩展不污染本地架构。
- 负面：v1 无法远程汇总；联邦学习链路（v3）前置成本高。

## 备选
- 默认上云：部署快但数据合规风险高，否决。
