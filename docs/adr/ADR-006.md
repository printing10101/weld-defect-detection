# ADR-006：评估回归门禁 + Golden Set 禁训练

- 状态：Accepted
- 日期：2026-08-04

## 背景
模型迭代若无硬性门槛，新权重可能静默回退精度（尤其缺陷检测的小目标/细裂纹）。

## 决策
- 固定 Golden Set（版本化、禁止训练）作为持续评估基准（§15.6）。
- 指标：mAP@0.5 / 每类 AP / 量化相对误差 / 评级一致率 κ / ECE。
- CI 回归门禁：PR 不得使 mAP@0.5 降 >1.0 点、一致率降 >2%、ECE 恶化 >0.02；否则阻断合并。
- 评估 harness 在 M4 接入 CI（当前占位注释）。

## 后果
- 正面：精度退化可被机械拦截；可复现、可追溯。
- 负面：需维护 Golden Set 标注与评估脚本成本。

## 备选
- 人工抽查：主观且不可复现，否决。
