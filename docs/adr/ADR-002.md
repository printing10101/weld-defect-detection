# ADR-002：检测用模型无关接口（默认 YOLO）

- 状态：Accepted
- 日期：2026-08-04

## 背景
检测器换代快（YOLO 每代迭代、RT-DETR/DETR 系并行发展），硬编码单一模型会导致三年内过时。

## 决策
- 领域层定义 `DefectDetector` Protocol（load/infer），推理编排只依赖接口。
- 默认实现 YOLOv8/v11(n)，导出 ONNX 由 ONNX Runtime 推理；新检测器以新增实现注入（§19.4 扩展菜谱）。
- 训练/服务预处理共用 `domain/preprocess/transform.py`（ADR-007）。

## 后果
- 正面：检测器可热替换，主干零改动；模型版本与运行时可并行管理。
- 负面：接口需保持稳定，新增能力先扩接口并经 ADR。

## 备选
- 直接绑定 Ultralytics API：开发快但锁定厂商/版本。
