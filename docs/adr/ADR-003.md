# ADR-003：标准适配层 + 版本化

- 状态：Accepted
- 日期：2026-08-04

## 背景
评级标准多元（NB/T47013.2、GB/T3323、ASME、ISO…）且会修订；判定数值须可追溯、可切换。

## 决策
- 领域层定义 `StandardGrader` Protocol（grade）。
- 每种标准一个实现模块 + `standards/tables/*.yaml` 数值表（loader 校验，§T8）。
- 每条记录携带 `standard_id` + `standard_version`；新版本并行支持，历史数据可比。

## 后果
- 正面：标准修订只加版本模块；多标准可插拔；判定可溯源到条款。
- 负面：数值表结构需稳定；未授权数值须熔断（authorized=false 不输出级别）。

## 备选
- 判定逻辑硬编码进代码：开发快但不可追溯、修订即重写。
