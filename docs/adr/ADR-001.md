# ADR-001：技术栈 Tauri + Vue3 + Python sidecar

- 状态：Accepted
- 日期：2026-08-04
- 决策者：项目负责人

## 背景
系统需同时承载重图像/ML 计算与原生桌面交互，且要求打包体积小、三年内不过时。

## 决策
- 桌面壳：Tauri 2.x + Vue 3 + TypeScript + Vite（表现层）。
- 算法/推理后端：Python 3.12（FastAPI），作为 Tauri `externalBin` sidecar，本地 REST（127.0.0.1 + 一次性 token）通信。

## 后果
- 正面：复用 Vue 生态；Python ML 栈零摩擦；体积远小于 PySide6 整包；前后端解耦。
- 负面：需维护两个运行时；Tauri 打包需 Rust 工具链（M6）；sidecar 进程生命周期管理。

## 备选
- PySide6 单进程：集成简单但体积大、前端体验弱。
- C#/WPF：ML 生态弱。
