## 1. 小目标检测：切片推理（SAHI）—— 最值得立即落地

**obss/sahi** — `github.com/obss/sahi`（**5,466★**，框架无关，持续维护，支持 YOLOv8/v11/ONNX）
- **思路**：Slicing Aided Hyper Inference——在大图上按**原始分辨率切片**（如 512/640 瓦片 + 重叠），
  每片独立推理后跨片 NMS/加权合并，专治"整体缩小后小目标变亚像素"的问题。
- **与本项目的对位**：当前 `YoloDetector._infer_onnx` 把 2448×2048 底片 letterbox 到 640×640——
  原本仅几个像素的气孔在缩小 3.8× 后几乎不可见（这正是气孔召回受限的机理之一）。
  合成数据/伪标签也继承了同样的尺度损失。
- **可落地**（P1+ 级别，无需训练）：
  - 新增 `backend/domain/detect/tiled_inference.py`：SAHI 式切片推理（瓦片 640、重叠 0.2、
    切片后跨片 NMS），作为 `YoloDetector.infer` 的可选路径（`detect.tiled: true` 开关，默认关）；
  - 与 P1-A 的 `infer_tta` 正交（可叠加）；
  - 验收：在 Golden Set 对比 整体推理 vs 切片推理 的气孔召回/mAP50。
- **成本**：低（纯推理侧，不改模型）；代价是耗时 ×(瓦片数)（GPU 上可并行）。
- **借鉴注意**：不要直接引 SAHI 重依赖（torchvision ops/多框架），自实现 200 行切片+合并即可，
  保持项目依赖干净。

## 2. 半监督 / 伪标签检测（对应 auto_pseudo_label 深化）

- **DenseTeacher** — `github.com/Megvii-BaseDetection/DenseTeacher`（131★，旷视）
  稠密伪标签半监督检测：对无标注图用教师模型产稠密伪标签（不只保留高置信框），
  学生模型同时学标签与伪标签分布。
- **MixPL** — `github.com/Czm369/MixPL`（71★）
  Mixed Pseudo Labels：伪标签 + MixUp/类别均衡，缓解伪标签类别不平衡。
- **与本项目的对位**：`auto_pseudo_label.py` 目前是"高置信阈值过滤"的最简 self-training 形态。
  借鉴点（不引入框架，取思想）：
  - **类别均衡伪标签阈值**：裂纹/未熔合等安全关键类可适当放宽 score 阈值、气孔收紧
    （与 `config.class_conf` 同哲学），避免伪标签加剧长尾；
  - **多尺度一致性**：同一图多尺度推理结果一致的框才采纳（与 P1-A `infer_tta` 联动）；
  - **教师-学生迭代**：每轮训练后用新模型重新产伪标签再训练（自举，闭环已具备）。
- **成本**：低-中（纯脚本/策略调整，不动训练框架）。

## 3. 开集 / 未知缺陷检测（罕见与未见缺陷类的兜底）

- **GroundingDINO** — `github.com/IDEA-Research/GroundingDINO`（**10,498★**，ECCV'24）
  文本提示开集检测：用自然语言描述（如"焊缝中的任何暗色指示""线性暗纹"）检测**不在
  训练类别集内**的缺陷——正是"模型封闭 6 类、未见缺陷全漏"的兜底方案。
- **Grounding-DINO-1.5-API**（1,143★）/ **T-Rex2**（2,698★，文本+视觉提示协同）
- **Awesome-Out-Of-Distribution-Detection**（1,018★，OOD 资料库）
- **与本项目的对位**：
  - **未知缺陷筛查层**：在 `YoloDetector` 检出之后叠加 GroundingDINO 零样本筛查
    （提示词："气孔、夹渣、裂纹、未熔合、未焊透、咬边，以及任何其他焊缝异常"），
    检出但未匹配 6 类 → 标记"未知缺陷/待人工"→ 高价值送标（与 P0-G 队列衔接）；
  - **预标注引擎**：GroundingDINO 产候选框 → 人工/自动确认 → 进训练池（扩类别，
    比硬编码 `ai_prelabel` 强得多）；
  - 红线：GroundingDINO 属**辅助筛查/预标注层**，不得参与评级（评级仍走 6 类
    `Nb47013Grader`，双轨纪律）。
- **成本**：中-高（需引入视觉语言模型推理；建议作独立进程/可选服务，不内嵌主链路）。

## 4. 置信度校准（深化 M4 不确定性）

- 校准方向无突出仓库（温度缩放等均可原生实现）——**不必借鉴，直接做**：
  - 温度缩放（Guo et al. 2017）：在验证集上优化温度 T，`p = softmax(logits/T)`，
    使 ECE 最小化；ONNX 侧可在导出时把温度烘焙进 sigmoid（改 `_infer_onnx` 的 sigmoid 步）；
  - 与 `estimate_uncertainty` 联动：校准后的 score 更可信 → `u_score` 置信度余量更有意义；
  - 用 ECE/MCE 指标在 Golden Set 上量化当前模型过自信程度（超参：温度 T∈[0.5,2] 网格搜索）。

## 优先级建议（相对当前状态）

| 优先级 | 方向 | 理由 | 前置 |
|---|---|---|---|
| **P1+（训练完成后可做）** | SAHI 切片推理 | 零训练成本直接提气孔/小缺陷召回，机理明确 | 本轮训练出基线模型 |
| **P1+** | 伪标签策略升级（类别均衡阈值/多尺度一致性） | 直接强化已落地的全自动标注，数据越滚越多 | 无 |
| **P2** | GroundingDINO 未知缺陷筛查 + 预标注引擎 | 解"未见缺陷全漏"的产品短板 | 需独立 VLM 服务 |
| **P2** | 温度缩放校准 | 深化 M4，提升 review_conf 可信度 | Golden Set 评估基线 |

## 风险与纪律
- SAHI/伪标签升级均**不改变评级主干**（双轨纪律）；GroundingDINO 只做筛查层，不碰
  `domain/grade`。
- 开集检测引入 VLM 推理成本与不确定性，输出必须带免责声明（与现行过渡路径一致）。
- 校准/切片均需在 Golden Set 复测，防止"指标好看、安全关键漏检"。
