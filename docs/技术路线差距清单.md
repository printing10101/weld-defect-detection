## 一、完全未实现

### G01 二维码档案追溯
- **PPT 出处**：总体目标 04"二维码追溯"；阶段4 交付物"二维码档案追溯"。
- **现状**：全库 grep `qrcode/QRCode/二维码` 零命中，requirements/pyproject 无相关依赖，报告版式（`backend/infra/reporting/pdf_reporter.py`）无二维码绘制。现有追溯仅审计日志哈希链（`backend/infra/db.py:9`）。
- **要补**：报告 PDF 嵌入二维码（内容指向报告指纹/档案 ID）；扫码查询端点（按码反查报告+底片+审计链）；依赖引入与离线生成（不联网）。
- **涉及**：`backend/infra/reporting/pdf_reporter.py`、`backend/app/routers/report.py`、新增 qrcode 依赖。
- **优先级**：P1（阶段4 交付物，可提前做，工作量小）。

### G02 云端存储 / 远程审核
- **PPT 出处**：总体目标"可云端协同"；阶段4"云端存储 / 远程审核"。
- **现状**：`backend/domain/sync.py:50-91` CloudAdapter 的 push/pull/federate 全部显式抛 `NotImplementedError`（v3 占位）；默认 `sync.kind=local`（`backend/app/dependencies.py:365-396`）；`backend/infra/egress_guard.py` 为零外联守卫，HTTP 推送通道同样被拦截；复核（routers/review.py）是本机闭环，非远程审核。
- **要补**：受控云通道（上传评估结果/报告索引而非原始底片）、远程审核端点、断点续传与冲突裁决；前提是先做 D01 架构决策。
- **涉及**：`backend/domain/sync.py`、`backend/infra/sync_io.py`、`backend/infra/egress_guard.py`、新增 sync 路由。
- **优先级**：P3（依赖 D01 决策；PPT 排期在阶段4）。

### G03 历史 RT 报告结构化
- **PPT 出处**：阶段1 第一条"历史 RT 报告结构化"。
- **现状**：`backend/training/` 下 swrd_converter / roboflow_ingest / steel_tube_ingest / build_real_manifest 均为训练数据集格式转换器；无纸质/Excel 历史 RT 报告导入工具（grep excel/openpyxl/历史报告 零命中）。
- **要补**：历史报告导入器（Excel/扫描件 → 结构化记录），OCR 可复用底片印字识别的 rapidocr 管线（`backend/domain/stamp.py`）；产出挂到 G06 的 Project 层级下。
- **涉及**：新增 `backend/training/rt_report_ingest.py` 或 `tools/` 脚本、`backend/infra/repository.py`。
- **优先级**：P1（阶段1 交付物；依赖 G06 数据层级先成型）。

## 二、任务1 数据底座与预处理

### G05 独立片号字段
- **PPT 出处**：任务1"数据标准化"（片号）。

### G06 训练数据关联专家等级与最终报告

- **涉及**：`backend/training/dataset_builder.py`、`backend/domain/labeling/`、`backend/domain/active_learning.py`。
- **优先级**：P1（复核回流数据的价值前提，与 G21 联动）。

### G07 亮度/对比度扰动鲁棒性验证
- **PPT 出处**：任务1"质量与鲁棒性验证——同一缺陷在不同图像条件下保持稳定检出与量化"。
- **现状**：完全缺失。`backend/training/augment.py:33` 的 RandomBrightnessContrast 仅训练增强；`backend/tests/test_detector_robustness.py` 实际内容是输入守卫/阈值回归，与扰动无关。

- **优先级**：P0（PPT 写明的验收路径，纯评估脚本、工作量最小）。

### G08 透视/几何畸变检测
- **PPT 出处**：任务1 步骤02"质量检查——透视、畸变、噪声检测"。
- **现状**：噪声/模糊/曝光/污渍门禁已有（`backend/domain/preprocess/metrics.py:332-412`）；全库无 homography/畸变检测算子。

### G09 非局部均值去噪
- **PPT 出处**：任务1 步骤03"双边 / 非局部均值去噪"。

### G10 背景校正与灰度归一化
