# 射线焊缝缺陷智能检测系统 — 用户手册

> 适用版本：0.1.0（单机版）。本手册面向持证评片人员、系统管理员与安全保密管理员。
> 安装、卸载与运行环境要求见《[安装与卸载指南](./安装与卸载指南.md)》。

---

## 1. 软件定位与安全须知

本软件用于工业射线底片（焊缝缺陷）的智能化辅助评片：对上传底片自动完成质量校验、缺陷检测、量化与标准评级建议，并生成评片报告。

**重要声明：所有 AI 检测、量化与评级结果均仅供辅助预筛，不具合规效力；最终评定结论必须由持证无损检测人员复核签发。** 每份报告均附带该免责声明。

数据安全口径：全部影像与结论数据仅在本机处理与存储，不联网上传；影像副本默认以国密算法（SM4）静态加密。

## 2. 启动与登录

1. 双击桌面 **ScanDetection** 图标启动。首次启动加载模型需 1～2 分钟，期间界面横幅提示"后端正在启动"，就绪后自动消失。
2. 进入登录页，选择角色并完成认证。系统实行**三员分立**：

| 角色 | 职责 |
|---|---|
| 系统管理员（sysadmin） | 日常评片业务、影像与档案管理 |
| 安全保密管理员（secadmin） | 密级管理、导出审批、载体台账 |
| 安全审计员（auditor） | 审计记录查阅与核查 |

3. 登录采用挑战-应答（SM2）方式，账号由系统管理员按《部署基线》预先创建。
4. 会话空闲 15 分钟自动锁定，需重新登录；同一账号同时仅允许一个会话，新登录会使旧会话失效。
5. 连续 5 次认证失败，账号锁定 30 分钟（同时产生安全告警与审计记录）。

> 单人科研使用场景可使用系统管理员账号以操作员姓名标识开展评片；正式涉密环境必须启用三员并分持账号。

## 3. 界面总览

主界面采用经典桌面布局：**菜单栏 → 功能区 → 标签页工作区 → 状态栏**。六个工作区通过"视图"菜单或快捷键切换：

| 工作区 | 快捷键 | 用途 |
|---|---|---|
| 单张检测 | Ctrl+1 | 逐张评片全流程（主工作区） |
| 批量检测 | Ctrl+2 | 成批提交与进度监控 |
| 档案检索 | Ctrl+3 | 历史检查记录查询 |
| 设备标定 | Ctrl+4 | 探伤设备/标定档案管理 |
| 底片查看 | Ctrl+5 | 大图查看器（窗宽窗位缩放） |
| 系统评价 | Ctrl+6 | 按 DB50/T 1807-2025 的系统级评价 |

"文件"菜单：打开影像（Ctrl+O）、批量导入（Ctrl+Shift+O）、退出。
"工具"菜单：操作员设置（设置当前操作员姓名，署名进入审计链）。
"帮助"菜单：快捷键表、关于（版本与依据标准）。

## 4. 单张检测流程

单张检测工作区按步骤条引导完成全流程：

### 4.1 上传影像
- 支持格式：PNG / JPG / BMP / TIFF / WebP / HEIC / PGM/PPM 等常规图像，以及 DICOM（`.dcm` `.dicom` `.ima`）。
- 单文件上限 200 MB。DICOM 自动读取拍摄参数（kV、曝光量、像素空间等），普通图像需手工指定**像素标定（mm/px）**。
- **母材厚度 T 为必填项**：不填写时标准评级功能将被锁定。

### 4.2 质量门禁（自动）
系统自动校验底片质量：黑度范围、IQI 像质计灵敏度、扫描分辨率（DPI）、位深等。未通过门禁的底片会被拦截并说明原因，同时归档留痕、写入审计链；可由授权人员在配置中按本单位规程放宽个别项（放宽会告警留痕）。

### 4.3 检测与量化（自动）
检测模型自动识别缺陷（气孔、夹渣、未焊透、未熔合、裂纹、咬边），给出位置、尺寸量化与置信度。**当前随包分发为基线检测模式时仅做辅助定位提示，类别判定需人工复核确认。**

### 4.4 结论与处置建议
系统按 NB/T47013.2-2015 给出综合级别建议与处置建议（可评片/需人工复核/不可评片），并解释判定原因。

## 5. 人工复核（缺陷增删改）

在复核面板中可对检测结果进行确认与修正：

- **改判类别 / 添加缺陷 / 删除缺陷**：均须填写复核理由（审计留痕必填项）。
- 删除缺陷与取消批量任务会弹出**二次确认框**，确认后才执行。
- 每次增删改后系统自动重新评级并重新生成报告。
- 复核提交需填写评片员姓名/工号与角色（初评 / 复评 / 仲裁），支持多级复核。

## 6. 批量检测

1. "文件 → 批量导入"或批量检测工作区选择多张影像（单批上限 100 张）。
2. 提交后显示实时进度（已处理/失败/预计剩余时间）；批量任务在后台独立运行，可切换其它工作区继续评片。
3. **取消批次**需二次确认：未处理影像停止处理，已完成结果保留。
4. 失败或被取消的任务支持**重试**（断点续跑，不重复已完成的影像）。
5. 长时间批量运行期间，系统自动监控内存与磁盘水位，超限产生告警并可在极端情况下触发自动重启恢复。

## 7. 报告与导出管控

- 每次评片自动生成 PDF 报告（含检测结果、评级建议、免责声明与数字签名验证入口）。
- 报告 PDF 与误报清单等资料的**下载受导出管控约束**（默认开启）：
  1. 系统管理员发起导出申请（注明用途）；
  2. **由另一名**安全保密管理员审批（申请人不能自审自批）；
  3. 审批通过后领取一次性导出令牌（10 分钟内有效、仅可用一次）；
  4. 凭令牌完成下载。
- 安全保密管理员本人经预授权可直接下载，但同样受批量导出行为监控：短窗口内高频导出会触发高级别安全告警。

## 8. 档案检索 / 底片查看 / 设备标定

- **档案检索（Ctrl+3）**：按时间、级别、密级等条件检索历史检查记录，查看报告与复核轨迹。
- **底片查看（Ctrl+5）**：对库内影像（含 TIFF/DICOM）以统一预览打开，支持放大观察缺陷区域。
- **设备标定（Ctrl+4）**：维护探伤设备与标定档案，评片时可关联设备信息。

## 9. 系统评价（DB50/T 1807-2025）

"系统评价"工作区面向检测系统自身的标准化评价：

- 装配附录 A 评价记录表（系统信息、透照布置、人员资质、检出统计），并导出记录表 PDF；
- 维护检测人员资质档案；
- 查看评价历史与等级曲线。

注意：标准数值表的官方授权版本未随软件分发，未授权状态下评级输出为参考值并带显著提示。

## 10. 备份与恢复

- 系统默认**每 24 小时**自动备份关键数据（数据库、模型注册表等，SM3 完整性校验）。
- 管理员可手动触发备份；恢复时系统先校验备份完整性（含防篡改校验）再执行回写。
- 影像目录默认不纳入自动备份（体积原因），重要项目建议按部署基线开启 `backup.include_images`。
- **静态加密主密钥 `data\.crypto_key` 不在自动备份范围内，必须随数据目录手工备份**；丢失将导致既有加密影像不可解。

## 11. 常见提示与处理

| 提示 | 含义与处理 |
|---|---|
| "后端正在启动或未连接，正在自动重试…" | 冷启动正常现象；持续超过 3 分钟见安装指南"常见安装问题" |
| "影像只在本机处理，不上传任何外部服务器" | 常驻隐私提示，无需处理 |
| 下载 PDF 返回无权限 / 需导出审批 | 走第 7 节导出管控流程 |
| 评级被锁定 | 未填母材厚度 T；补充后重新评级 |
| 403 / 账号锁定 | 越权操作或连续认证失败；等待锁定期满或由管理员处理 |
| "模型加载中" | 当前为基线检测模式或模型仍在加载，检测结论以人工复核为准 |

## 12. 已知限制

- AI 检测模型对稀有缺陷类别（裂纹、未熔合等）的训练样本有限，漏检/误检风险高于常见类别（气孔等），**必须人工复核**。
- 军用标准（GJB 1187A）评级数值表未获授权，该标准路径下评级一律熔断为"不可自动评级"。
- 本软件为单机软件，不提供在线更新；升级须按《安装与卸载指南》重新安装。
- 详细的精度指标与验证状态见项目 README 的"已知限制"章节。
