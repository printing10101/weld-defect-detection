## 二、推荐获取顺序（按价值/可行性）

### 1. SWRD —— 最理想，务必优先（需人工）
- **为什么**：3675 张真实 X 光底片，6 类缺陷与 ScanDetection 的 DefectClass **完全对齐**（class_map.py 已内置映射）；CC BY 4.0 可商用。
- **怎么拿**：浏览器打开 **http://www.tz-ndt.com**（注意：https 证书异常，用 http），注册账号 → 登录 → 下载页申请下载。
  - 项目已有引导：『python -m backend.training.download_swrd --guide』
- **拿到后**：解压到 data/external/swrd/，运行『python -m backend.training.download_swrd --ingest』（自动转 YOLO 6 类 + 装配训练集）。
- **合规**：按 data/DATA_LICENSE.md 署名 SWRD 作者（Gao, Y. et al.）。

### 2. 百度网盘两个真实射线数据集（国内用户最方便，需人工）
- **来源**：https://github.com/admin1523/Weld-defect-detection-datasets
- **数据集 1**：真实工业射线胶片，含未焊透/气孔/夹渣/未熔合/裂纹等：https://pan.baidu.com/s/1gZBmIyyV1NCvUP2NUUxMgQ?pwd=gyxi
- **数据集 2**：跨条件射线图像（更难的弱对比样本）：https://pan.baidu.com/s/1mf3gkusHvUvokVvlW_tKuA?pwd=2dut
- **注意**：README 未说明标注格式，下载后需人工确认是否有缺陷框标注；**非商用**许可。

### 3. Roboflow Danila 『X-ray Weld Defect』（Public Domain，最合规补充）
- **为什么**：Public Domain 无许可负担，416 张 X 光焊缝，roboflow_ingest.py 已支持。
- **怎么拿**：浏览器打开 universe.roboflow.com 搜索『X-ray Weld Defect』（Danila 出品）→ Export → YOLOv8 → Download（需 Roboflow 账号，免费）。
- **拿到后**：zip 解压到 data/external/roboflow/danila/，运行『python -m backend.training.roboflow_ingest --name danila』。

### 4. GDXray welds（真实 X 光，但非商用 + 需梯子）
- 官方页：https://domingomery.ing.uc.cl/material/gdxray/ （作者主页，已验证可达）
- 下载：页面内 Dropbox 链接（本机被墙；有梯子可直接下）。Welds 组约 3200 张真实底片。
- **许可**：仅限研究/教育（页面明确『free of charge for research and educational purposes』），**不可商用**。
- **拿到后**：GDXray 原生格式（PNG + 论文标注说明），需自行转 YOLO；建议仅研究/竞赛使用。

### 5. steel-tube（✅ 已下载并接入训练管线，2026 实测）
- https://github.com/huangyebiaoke/steel-pipe-weld-defect-detection/releases/tag/1.0
- **镜像下载法**：GitHub 直连限速 0.03MB/s，改用加速镜像 `https://gh-proxy.com/https://github.com/...` 达 **5.8MB/s**（快 190 倍），773MB 约 2.5 分钟完成。
- **已验证**：图像为灰度射线底片（958×653，RGB 通道差 0.0）；8 类 YOLO 格式。
- **已接入**：`backend/training/steel_tube_ingest.py` 将 8 类映射到项目 6 类（跳过断弧/夹珠/焊瘤），转换 **2699 张图 / 5873 有效框**（含裂纹 119、未熔合 408、夹渣 120、咬边 35）；已并入 `dataset_builder`，重建训练集 2999 张（train 2370 / val 293 / test 336）。
- ⚠️ 许可 GPL-3.0（代码），数据集许可未明；商用请注意传染风险，或仅用于研究/内部。

### 6. HF rikkarth（已下载，域预训练用）
- data/external/hf/rikkarth/（99MB，2028 张，CC0，3 类外观）——非 X 光，但可作焊缝外观预训练。

## 三、类别映射表（各源 → ScanDetection 6 类）

backend/training/class_map.py 已实现以下映射（map_source_label）：

| DefectClass | SWRD/英文 | 中文 | steel-tube |
|---|---|---|---|
| POROSITY (0) | porosity | 气孔 | air-hole |
| SLAG (1) | inclusion / slag | 夹渣/夹杂 | slag-inclusion |
| INCOMPLETE_PENETRATION (2) | lack_of_penetration | 未焊透 | — |
| LACK_OF_FUSION (3) | lack_of_fusion | 未熔合 | unfused |
| CRACK (4) | crack | 裂纹/裂缝 | crack |
| UNDERCUT (5) | undercut / concavity | 咬边/内凹 | bite-edge |
| （不映射） | — | — | broken-arc / hollow-bead / overlap |

> steel-tube 的 broken-arc(断弧)/hollow-bead(夹珠)/overlap(焊瘤) 无对应类，**不要映射**（避免错误标注污染训练）。

## 六、GitHub 加速镜像下载法（关键技巧，2026 实测有效）

GitHub 直连大文件被限速至 0.03MB/s，用加速镜像可到 **2.6–5.8MB/s**（快 100–190 倍）：

```
# 在任意 GitHub 下载 URL 前加前缀：
https://gh-proxy.com/https://github.com/<owner>/<repo>/archive/refs/heads/main.zip
https://ghfast.top/https://github.com/<owner>/<repo>/releases/download/<tag>/<file>
```

实测：
- steel-tube 773MB：gh-proxy.com 5.8MB/s，约 2.5 分钟（直连需 7 小时）
- Linkesh 452MB：ghfast.top 2.6MB/s
- ⚠️ 大文件下载务必验证完整性（zip 会因中断产生『End of Central Directory』错误），失败换另一个镜像重试。
