| 恢复演练 / 长跑脚本跨平台 | `scripts/recovery_drill.py`、`scripts/soak_72h.py` 纯 Python+numpy | 已验证（Windows/Linux CI 语义一致，长跑仅冒烟时长实测） |

**麒麟 V10 / UOS 构建步骤（S-02，未真机验证，逐步诚实标注）**：

1. 安装 Tauri Linux 依赖（Debian 系）：
   `sudo apt install libwebkit2gtk-4.1-dev build-essential libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`
   （麒麟/UOS 软件源包名可能有差异——待真机核对）
2. 准备 Python 侧车：`python3 -m venv python_embed`（或 pyenv 装机后建 venv），
   安装 `backend/requirements.lock`；Linux 布局解释器路径为
   `<安装目录>/python_embed/bin/python3`（`main.rs` 已按平台条件编译适配）。
3. 前端：`cd src && pnpm install --frozen-lockfile && pnpm build:pkg`。
4. 打包：`bash src/src-tauri/scripts/build-linux.sh`（等价于
   `cargo tauri build --bundles deb,appimage`）。
5. 产物：`src/src-tauri/target/release/bundle/{deb,appimage}`；安装后验证后端自启、
   模型加载、评片与报告链路，并回填验证记录表。
