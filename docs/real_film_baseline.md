## 3. 关键结论

1. **部署模型可用（重要纠偏）**：单张底片探测曾误判模型"均匀低置信失效"，
   但全量 165 张扫描显示 `models/weights/best.onnx`（2026-08-16）置信健康——
   逐图 max_conf **中位 0.83 / P90 0.93 / 最大 0.97**，部署阈值 0.3 下检出 135/165 张。
   ONNX 部署路径**功能正常**，此前"失效"结论源于抽样到难例（如 PG101-1-1）。

2. **整体中等水平**：mAP@0.5≈0.74 可作为后续迭代的回归基线门槛。

3. **罕见/重大缺陷的瓶颈是"精确"而非"召回"**：裂纹/未熔合/未焊透召回已达 0.8–1.0，
   但精确仅 0.25–0.39——模型**过度预测**这类缺陷（大量假阳性）。
   这与 `class_conf` 对稀有/安全关键类设极低阈值（裂纹 0.05、未熔合 0.08）以"优先召回"的设计一致，
   但暴露了模型对稀有类的判别力不足。路线图"罕见类召回"问题实际应重新表述为
   **"罕见类精确 / 误报抑制"**。

4. **气孔仍是主召回缺口**：作为绝对多数类，其 ~28% 漏检主导整体召回损失，
   是数据扩量与难例挖掘的首要对象。

## 4. 切勿部署的废弃模型

- `data/real_label/runs/yolo11n_real2/train/weights/best.onnx`（2026-08-08）经验证**置信均匀偏低**
  （逐图 max_conf 中位 0.18、最大 0.59），属历史坏导出，**不可作为部署权重**。
- 仅 `models/weights/best.onnx`（2026-08-16）经全量扫描验证为可用部署模型。

## 5. 对后续路线图的输入

- **数据扩量**：稀有类真值极度匮乏（裂纹 GT=1、未熔合=5、夹渣=7）。
  提升罕见类**精确**需更多真实标注样本 + 难例增强，而非继续降低阈值。
- **M4 不确定性/校准**：罕见类低精确说明低置信预测中混有大量假阳性；
  `review_conf` 人工复核兜底须能有效拦截（裂纹/未熔合类尤甚）。
- **回归门禁**：建议将本基线（mAP@0.5≥0.736、召回≥0.725）接入 §15.6 门禁，
  任何权重替换不得使其退化 >1.0 点。
- **禁止用于训练**：本 165 张为固定评估集，禁止进入训练集（遵循 Golden Set 原则）。
