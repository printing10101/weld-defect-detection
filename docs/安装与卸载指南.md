# 射线焊缝缺陷智能检测系统 — 安装与卸载指南

> 适用版本：0.1.0（Windows x64 安装包）。本说明面向负责安装本软件的操作人员与部署管理员。

---

## 1. 运行环境要求

| 项目 | 最低要求 | 推荐配置 |
|---|---|---|
| 操作系统 | Windows 10 64 位（1903 及以上） | Windows 11 64 位 |
| 处理器 | x86_64 双核 | x86_64 四核及以上 |
| 内存 | 4 GB | 8 GB 及以上 |
| 硬盘剩余空间 | 2 GB（安装约 600 MB，含嵌入式 Python 运行时） | 5 GB 及以上（预留影像库与数据库增长空间） |
| 屏幕分辨率 | 1280 × 800 | 1920 × 1080 |
| 网络 | **无需联网**（全流程本地处理，不外传任何数据） | 同左 |
| 运行库 | WebView2 Runtime（Windows 11 自带；Windows 10 缺失时安装器会自动引导安装） | — |

说明：
- 本软件为单机版，安装后以本机回环地址（127.0.0.1:18773）提供本地服务，不对外监听。
- Linux（deb/AppImage）与国产化平台（飞腾/鲲鹏/麒麟 V10/UOS）适配状态见 `docs/国产化适配矩阵.md`；其中标注"待真机"的条目尚未完成实机验证。

## 2. 安装步骤

1. 获取安装包 `ScanDetection_0.1.0_x64-setup.exe`，建议先核对发布方提供的文件校验值。
2. 双击运行安装向导（首次运行可选中文/English 界面语言）。
3. 按向导提示完成安装。默认安装模式为"仅当前用户"，无需管理员权限；快捷方式默认创建于桌面与开始菜单。
4. 安装完成后从桌面或开始菜单启动 **ScanDetection**。

### 首次启动须知

- 首次启动需要完成嵌入式 Python 运行时加载与模型初始化，**可能需要 1～2 分钟**。此期间界面顶部会出现"后端正在启动"横幅，属正常现象；就绪后横幅自动消失。
- 首次使用影像归档功能时，系统会在数据目录自动生成本地静态加密主密钥文件 `data\.crypto_key`。
  **该文件必须随 `data` 数据目录一并备份妥善保管：密钥文件丢失后，既有加密影像副本将无法解密。**
- 正式使用前，请由保密管理员按 `docs/deployment-baseline.md` 完成三员账号引导与运行基线配置，并确认合规自检全部检查项通过。

## 3. 目录说明

| 位置 | 内容 |
|---|---|
| 安装目录 | 程序本体、嵌入式 Python、后端服务、模型资源（不含业务数据） |
| `%APPDATA%\com.scandetection.sd\data\` | **业务数据目录**：业务数据库（scan.db）、加密影像副本、评片报告、审计链、备份、**静态加密主密钥（.crypto_key）**。独立于安装目录存放，卸载/重装均不受影响 |
| `%LOCALAPPDATA%\ScanDetection\logs` | 运行日志（自动轮转，单文件 5 MB，最多保留 20 份） |

> 业务数据存放在用户数据目录（`%APPDATA%`）而非安装目录：卸载只移除程序文件，
> 数据目录默认保留；重装后数据自动恢复可见。

## 4. 升级与数据保护

- 当前版本未内置在线更新，升级请获取新版本安装包重新安装（数据目录自动沿用）。
- 由旧版本（数据存于安装目录 `data\`）升级/卸载时，安装器会在卸载前把旧数据自动备份到 `%APPDATA%\com.scandetection.sd\data`，不会丢失。
- 系统默认每 24 小时自动备份关键状态（数据库/模型注册表等，SM3 校验），也可在系统菜单中手动触发备份与恢复。升级前建议手动执行一次备份。

## 5. 卸载步骤

1. 关闭 ScanDetection 应用窗口（后端服务会随之自动退出）。
2. 打开 Windows「设置 → 应用 → 安装的应用」，找到 **ScanDetection** 点击卸载；或使用开始菜单程序组中的卸载入口。
3. 卸载仅移除程序文件，`%APPDATA%` 下的数据目录与日志目录默认保留。**如确需彻底清除全部涉密数据，请在卸载后经审批流程手工删除数据目录**（`%APPDATA%\com.scandetection.sd` 与 `%LOCALAPPDATA%\ScanDetection`，含加密影像、数据库与主密钥文件），并按本单位介质管理规程处置。

## 6. 常见安装问题

| 现象 | 处理 |
|---|---|
| 启动后长时间显示"后端正在启动" | 首启加载需 1～2 分钟；超过 3 分钟仍无响应，查看 `%LOCALAPPDATA%\ScanDetection\logs` 日志反馈维护方 |
| 提示端口 18773 被占用 | 确认没有其他本机程序占用该端口（`netstat -ano \| findstr 18773`）；本软件要求独占该本机端口 |
| Windows 10 提示缺少 WebView2 | 按安装器引导安装 WebView2 Runtime 后重试 |
| 下载报告 PDF 提示无权限 | 报告导出受导出管控（审批/一次性令牌）约束，属安全设计；联系保密管理员开通（见用户手册第 7 节） |
